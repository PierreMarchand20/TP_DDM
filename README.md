# Domain decomposition project

## Setup (for Linux/Mac)

In the root of this repository:

- Create a virtual environment

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip setuptools wheel
```

- Install dependencies

```bash
pip install .
```

## Usage

Add your scripts to the folder `ddm_project`. To run them,

- Activate the virtual environment

```bash
source .venv/bin/activate
```

- Run your script, for the example given in this repository:

```bash
python3 ddm_project/example_overlap.py
```
